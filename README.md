# GophKeeper

Проект разработан **BigSm0uk** и **Mihklz**.

Реализован TUI-клиент, который позволяет:
- загружать файлы на сервер;
- работать с локальными данными на клиенте.

В качестве основы взаимодействия между клиентом и сервером используется **gRPC**, а для работы с proto-схемами применяется **buf**.  
Swagger-документация по API генерируется автоматически на основе proto-схем.

Для запуска проекта используется **Taskfile** (`task`).

### Предварительные шаги

- **Генерация RSA-ключей для JWT (асимметричное шифрование)**:

```bash
task server:jwt:generate-keys
```

- **Генерация gRPC-кода** (требуется VPN для доступа к репозиториям):

```bash
task proto:gen
```

- **Запуск базы данных в Docker**:

```bash
task docker:db:up
```

### Запуск сервера

- **Сборка и запуск сервера**:

```bash
task server:run
```

- **Запуск сервера в dev-режиме (без сборки, через `go run`)**:

```bash
task server:run:dev
```

После запуска сервера и в development-режиме (`IS_DEV=true` в конфиге) Swagger UI будет доступен по адресу:

```text
GET http://<HTTP_HOST>/swagger
```

### Запуск клиента (TUI)

- **Сборка и запуск клиента**:

```bash
task client:run
```

- **Запуск клиента в dev-режиме (через `go run`)**:

```bash
task client:run:dev
```
